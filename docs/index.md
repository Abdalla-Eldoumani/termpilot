# termpilot documentation

A Model Context Protocol server that drives terminal sessions. This is the public reference manual.

If you're new, start with [getting-started.md](getting-started.md). If you know what termpilot is and want the API, jump to [tool-reference.md](tool-reference.md). If you're shipping termpilot to production, read [security.md](security.md) first.

## Table of contents

- [Getting started](getting-started.md), install, configure your MCP client, run the first session
- [Tool reference](tool-reference.md), every tool with its inputs and outputs
- [Security model](security.md), threat model, sandboxing, audit log, hardening recipes
- [Recipes](recipes.md), REPL exploration, build verification, OS testing, debugger sessions
- [Architecture](architecture.md), internals, design choices, the trade-offs we made
- [FAQ](faq.md), common questions and answers
